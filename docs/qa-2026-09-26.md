# QA pass: first released ISO (2026-09-26)

Image: `sg-live-20260926-d65702f.iso` (sha256 `d121e172...`), booted as a CD
in a private QEMU (OVMF UEFI, KVM, 6 GB, 4 CPUs, a fresh 32 GB virtio disk,
virtio-vga at 1280x800, intel-hda, usb-tablet), driven only through QMP
(keys, mouse, screendumps). Every screenshot was looked at. Running report:
items are added as the walk goes on.

Legend: **Fixed in** names the version that carries the fix; "open" is not
fixed yet; "reported" went to the owning worker.

## Critical

| # | What | Fixed in |
|---|------|----------|
| B1 | The released ISO runs OpenSSH on `*:22` with root's `authorized_keys` = the boot gate's test key, and **machines installed from it keep both**: whoever has that private key has root on every live session and every install. Now no key in the image; gates pass theirs as a systemd credential (QEMU `-smbios type=11`); sshd runs only when a key was provisioned; the image build refuses a baked key. Verified on the VM both ways. **Existing installs: delete `/root/.ssh/authorized_keys`** (an update note is needed). | sg-image `ecda63d` |
| B30 | The PDF Viewer shows blank pages for any PDF without bookmarks (most PDFs): `sg-pdf`'s outline request raised on poppler's NULL index iterator and the exception ended the bridge. | sg-session 0.1.0-33 |
| B31 | Media Player crashed on any video: every signed-in program logged `Failed to read display config` (the display keys' containers under `HARDWARE\DEVICEMAP\VIDEO` and the hardware profile could not be created by a session), so DirectDraw had no primary surface. Also behind B22 (0 x 0 resolution) and B49. | wine-sg 10.0-64 (0242) |
| B44 | **Start > Shut down / Restart did nothing** (Wine's ExitWindowsEx only ends the Windows session). Now it asks logind after the session's programs close; a polkit rule lets a local user shut down. Verified: Restart rebooted the VM. | wine-sg 10.0-64 (0241), sg-session 0.1.0-34 |
| B46 | **The first-run setup's browser (Firefox) never installed**: `sg-oobe-browser` used curl, which the image lacks ("curl: not found" every boot). Now `sg-fetch` (HTTPS-only urllib). Verified: Firefox installed in 40 s. | sg-session 0.1.0-35 |
| B49 | Starting Firefox froze the whole shell (clock stopped, Start dead): its GPU process spun with the wineserver because `DwmFlush`'s refresh grid comes from the unreadable display config (B31). | wine-sg 10.0-64 (0242) |
| B53 | Firefox crashed on its first page ("No such local time"): `GetTimeZoneInformation`/`...ForYear` failed for every signed-in user (kernelbase opened HKLM's Time Zones and Nls keys with full access). Code page and language-group enumeration were empty too. | wine-sg 10.0-66 (0243) |
| B52 | Each Firefox start left `explorer.exe /desktop` processes spinning at 100% CPU forever (an assert in the display setup under the sandbox's token on its own desktop), until thread creation failed. | wine-sg 10.0-66 (0247) |
