# QA pass: first released ISO (2026-09-26)

Image: `sg-live-20260926-d65702f.iso` (sha256 `d121e172...`), booted as a CD
in a private QEMU (OVMF UEFI, KVM, 6 GB, 4 CPUs, a fresh 32 GB virtio disk,
virtio-vga at 1280x800, intel-hda, usb-tablet), driven only through QMP
(keys, mouse, screendumps). Every screenshot was looked at. Running report:
items are added as the walk goes on.

Legend: **Fixed in** names the version that carries the fix; "open" is not
fixed yet; "reported" went to the owning worker.

## Critical

| # | What | Fixed in |
|---|------|----------|
| B1 | The released ISO runs OpenSSH on `*:22` with root's `authorized_keys` = the boot gate's test key (`sg-image/build/ssh/id_ed25519.pub`). Whoever has that private key has root on every live session (and on installs, if it is copied -- checking). | open |
| B30 | The PDF Viewer shows blank pages for any PDF without bookmarks (most PDFs): `sg-pdf`'s outline request raised on poppler's NULL index iterator and the exception ended the bridge. | sg-session 0.1.0-33 |
| B31 | Media Player crashes opening an H.264/AAC `.mp4`: VMR-7 cannot create its DirectDraw primary surface and quartz dereferences NULL. Root cause under investigation: every session logs `Failed to read display config` because `HKLM\HARDWARE\DEVICEMAP\VIDEO` cannot be created by a session (volatile hive; filtered admin token) -- also behind B22. | open (wine-sg) |
